# L1br3

**Free software for everyone.** Open-source tools that empower users, respect
privacy, and remain accessible to all — no paywalls, no tracking, just useful
code.

Website: **[l1br3-io.github.io/libre-website](https://l1br3-io.github.io/libre-website/)**

## Engineering themes

Systems Rust · Wayland/COSMIC-native · ship-everywhere release engineering
(winget, Homebrew, AUR, cargo-binstall, deb/rpm/AppImage, Docker, installable
PWAs) · built in the open with CI, architecture decision records, and
roadmaps in each repository.
