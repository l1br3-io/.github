code.

## Engineering themes

Systems Rust · Wayland/COSMIC-native · ship-everywhere release engineering
(winget, Homebrew, AUR, cargo-binstall, deb/rpm/AppImage, Docker, installable
PWAs) · built in the open with CI, architecture decision records, and
roadmaps in each repository.
